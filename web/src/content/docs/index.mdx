## Why choose papermint?

<CardGrid stagger>
  <Card title="⚡ Microsecond Encoding" icon="rocket">
    Zero-allocation hot paths and pure Rust performance. Format 50-item restaurant receipts with barcodes and logos in ~10 microseconds.
  </Card>
  <Card title="📐 Typographic Precision" icon="pencil">
    Built on Unicode East Asian Width (UAX #11). Asian characters (CJK), emojis, and Latin letters align to the exact monospace dot without table distortion.
  </Card>
  <Card title="🖨️ Multi-Vendor Dialects" icon="laptop">
    Epson ESC/POS and StarPRNT Line Mode out of the box. Build your receipt once, print across Epson, Star, Bixolon, Citizen, and generic printers.
  </Card>
  <Card title="🔌 Driverless Transports" icon="puzzle">
    Print over Async TCP (Port 9100), pure user-space driverless USB (`nusb`), RS-232 serial, or Bluetooth Classic (SPP) without vendor drivers or sudo.
  </Card>
  <Card title="📱 Mobile & Cloud Ecosystem" icon="star">
    First-class Node.js/TypeScript N-API bindings, lightweight HTTP REST print daemon (`papermintd`), and C-ABI for Expo SDK 56+ Inline Modules.
  </Card>
  <Card title="🛡️ Hardware Protection" icon="shield">
    Automatic 960-dot image chunking to prevent volatile thermal RAM overflows, plus Floyd-Steinberg and Atkinson dithering algorithms.
  </Card>
</CardGrid>
